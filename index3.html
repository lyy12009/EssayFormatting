🎓 學術論文與頁碼混排 VBA 巨集產生器

專為論文後端總整設計：設定邊界、混排頁碼，並**僅微調目錄樣式**，完美保護已透過 JSON 整理好的正文文本。

🔒 安全聲明： 本巨集不會動到正文（Normal）樣式，完全保留您先前透過 Python JSON 合約產生的初級排版成果！

1. 論文頁面邊界設定 (cm)

2. 目錄 (TOC) 專屬樣式微調

3. 頁碼混排與分節邏輯

4. 生成的論文 VBA 巨集程式碼

📖 如何在 Word 中使用此巨集？

  1. 在正文第一章的最前方插入一個分節符號（版面配置 ➔ 分隔設定 ➔ 分節符號：下一頁）。
  2. 按下快捷鍵 Alt + F11 開啟 VBA 編輯視窗，點選 插入 ➔ 模組 (Module)。
  3. 貼入右側程式碼，關閉視窗。回到 Word 按 Alt + F8 執行 ApplyThesisPostFormatting 即可！
