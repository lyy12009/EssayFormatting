📚 學術專書與出版品專用 VBA 巨集產生器

專為專書出版設計：設定鏡像裝訂邊、全書阿拉伯數字貫穿、**獨立微調目錄樣式**，絕不干擾已整理好的正文。

🔒 安全聲明： 本巨集不會動到正文（Normal）樣式，完全保留您先前透過 Python JSON 合約產生的初級排版成果！

1. 專書裝訂與邊界設定 (cm)

2. 目錄 (TOC) 專屬樣式微調

3. 專書頁首與出版慣例

4. 生成的專書 VBA 巨集程式碼

📖 如何在 Word 中使用專書巨集？

  1. 開啟專書原稿檔案，按下快捷鍵 Alt + F11 開啟 VBA 編輯視窗。
  2. 點選 插入 ➔ 模組 (Module)，貼入右側專書 VBA 程式碼。
  3. 回到 Word 畫面，按 Alt + F8 執行 ApplyBookPostFormatting 即可！
